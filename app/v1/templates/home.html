The UniBrain Ontology

UniBrain organizes academic life into connected entities. When you ask UniAssist a question, it doesn’t just answer — it traverses relationships and applies rules.

Ontology Map
Entities + relationships

Requirement core • electives

Program / Degree evaluation output
UniBrain stores relationships explicitly so UniAssist can explain “why” — not just answer.

Student → Courses

UniBrain separates what you’ve finished vs what you’re currently taking, so recommendations are realistic (no “take a class you’re literally enrolled in” energy).

Courses → Requirements

Requirements aren’t just “a list.” They have categories, credit constraints, and sometimes multiple valid ways to satisfy them.

Requirements → Rules

Rules describe the logic: prerequisites, substitutions, exceptions, minimum grades, repeated course limits, and conditional “if-then” policy behavior.

Rules → Degree Pathways

UniBrain can evaluate pathways: what’s satisfied, what’s missing, and what your next best options are — with clear reasoning.

FAQ

Quick answers so you can keep scrolling with confidence.

Is UniBrain just a chatbot?

No — UniAssist is the interface. UniBrain is the underlying ontology + rules system that drives consistent answers.

How do substitutions and exceptions work?

They’re represented as explicit rules tied to programs and requirements, so UniBrain can validate and explain them.

Can UniBrain handle multiple pathways?

Yes. Requirements can have multiple satisfaction options, and UniBrain can evaluate alternative routes with tradeoffs.

Are all the routes built right now?

No. This landing page is built with a first version demo for you to try out! UniAssist can start as a UI stub and evolve.
